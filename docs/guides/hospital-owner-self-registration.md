# คู่มือ OWNER: การลงทะเบียนเองด้วยเลขบัตร

ผู้ดูแลโรงพยาบาลสามารถเตรียมบัญชีบุคลากร อสม. และผู้ป่วยใน DEMI ตามขั้นตอนเดิมได้ ผู้ที่ได้รับการเตรียมบัญชีแล้วเลือกเปิด `/register` กรอกเลขบัตรประชาชน ยืนยันชื่อที่ระบบแสดงแบบปกปิดบางส่วน และตั้งรหัสผ่านได้โดยไม่ต้องใช้ลิงก์เชิญ การเชิญด้วยลิงก์และการช่วยเปิดใช้งานต่อหน้ายังใช้ได้เหมือนเดิม

ระบบเปิดรับการลงทะเบียนเองเป็นค่าเริ่มต้น เฉพาะ OWNER โดยตรงของโรงพยาบาลที่ยังใช้งานอยู่เท่านั้นที่เปลี่ยนค่าได้ ไปที่ **ตั้งค่า → อนุญาตให้ลงทะเบียนเองด้วยเลขบัตร** (`/app/settings`) แล้วปิดสวิตช์เพื่อหยุดการค้นหาและการเปิดบัญชีใหม่ของโรงพยาบาลนั้นทันที การปิดสวิตช์ไม่เปลี่ยนบัญชีที่เปิดใช้งานไปแล้ว

รายชื่อบุคลากรและผู้ป่วยแสดงเครื่องหมาย **ลงทะเบียนเองเมื่อ <วันที่>** เมื่อบัญชีเปิดผ่านช่องทางนี้ สามารถกรองรายชื่อด้วยสถานะ “ลงทะเบียนเอง” ได้ เครื่องหมายนี้เป็นช่องทางแจ้ง OWNER ในระบบปัจจุบัน; DEMI ยังไม่มี inbox แจ้งเหตุการณ์นี้

## ข้อควรทราบ

- ผลค้นพบหรือไม่พบช่วยให้ผู้ใช้ทราบว่าเลขบัตรถูกเตรียมบัญชีไว้หรือไม่ สำหรับผู้ป่วย การพบข้อมูลอาจเปิดเผยว่าเข้าร่วมโครงการ NCD ของโรงพยาบาล
- ผู้ที่มีสำเนาบัตรของผู้อื่นอาจลงทะเบียนก่อนเจ้าของบัตรได้ และบัญชีใหม่อาจเข้าถึงข้อมูลสุขภาพตามสิทธิ์ที่ผูกกับบัญชีนั้น
- หากโรงพยาบาลไม่ยอมรับความเสี่ยงนี้ ให้ปิดสวิตช์และใช้ลิงก์เชิญหรือช่วยเปิดใช้งานตามขั้นตอนเดิม
- ก่อนใช้กับข้อมูลจริง หน่วยงานพันธมิตรต้องรับทราบการเปิดเผยข้อมูลและความเสี่ยงนี้ตาม ADR-0020 และ RELEASE_GATE G-01.
