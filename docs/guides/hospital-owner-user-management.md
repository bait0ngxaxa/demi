# คู่มือ OWNER: จัดการผู้ใช้งาน (บุคลากร อสม. และผู้ป่วย)

เมนู **บริหารโรงพยาบาล → ผู้ใช้และสิทธิ์** (`/app/users`) รวมบุคลากร อสม. และผู้ป่วยของโรงพยาบาลที่คุณเป็นเจ้าของไว้ในหน้าเดียว ใช้ได้เฉพาะเจ้าของโรงพยาบาล (OWNER) ที่ยังใช้งานอยู่ ระบบตรวจสิทธิ์ทุกครั้งที่เปิดหน้าหรือกดดำเนินการ

การเพิ่มบุคลากร/อสม. และการนำเข้าผู้ป่วยจาก Excel ยังทำที่หน้าเดิม (มีปุ่มลัดอยู่ด้านบนของหน้า) งานบุคลากรและการนำเข้ารายชื่อยังเปิดได้จากปุ่มใน directory นี้

การเปิดบัญชีผู้ป่วยเริ่มจาก **รายชื่อผู้ป่วย → รายละเอียดผู้ป่วย → จัดการผู้ป่วย** ระบบเปิดหน้าการเปิดใช้งานเดิมโดยส่งความสัมพันธ์ผู้ป่วยกับโรงพยาบาลที่เลือกไว้ให้ตรงรายการ การเปิดใช้งานครั้งแรกยังแยกจากการคืนรหัสผ่าน ซึ่งต้องยืนยันตัวตนตามขั้นตอนคืนบัญชี

## รายชื่อ

- แท็บ **บุคลากร · อสม. · ผู้ป่วย** และตัวกรองทั้งหมดอยู่ใน URL จึงคัดลอกลิงก์หรือกดย้อนกลับได้
- **สถานะ:** รอลงทะเบียน (ยังไม่เปิดใช้งานบัญชี) · ใช้งานอยู่ · ระงับ (ระงับสิทธิ์ในโรงพยาบาล หรือบัญชีถูกล็อก) · นำออกแล้ว
- **วิธีเปิดใช้งาน:** ลงทะเบียนเอง (ด้วยเลขบัตรที่ `/register`) · ลิงก์เชิญ · ช่วยเหลือ (เปิดใช้งานต่อหน้าเจ้าหน้าที่) · ยังไม่เปิดใช้งาน
- ค้นหาด้วยชื่อ สำหรับผู้ป่วยค้นหาด้วย HN ได้ด้วย
- แต่ละรายการแสดงวันและช่องทางของ **รีเซ็ตรหัสผ่านล่าสุด** หากเคยรีเซ็ตสำเร็จ โดยไม่แสดงเลขบัตรหรือผู้ดำเนินการ

## หน้ารายละเอียด

ทุกประเภทใช้รูปแบบเดียวกัน

1. **หัวเรื่อง:** ชื่อ ประเภท และสถานะ
2. **การเปิดใช้งาน:** วิธีเปิดใช้งาน วันที่เปิดใช้งาน วันที่เพิ่มเข้าระบบ ผู้เพิ่ม และป้าย “ลงทะเบียนเอง” พร้อมวันที่
3. **ประวัติบัญชี:** เพิ่มเข้าระบบ ออก/ยกเลิกลิงก์ เปิดใช้งาน ระงับ คืนสิทธิ์ แก้ชื่อ นำออก และล็อกบัญชี
4. **การดำเนินการ:** แต่ละข้อมีคำอธิบายผลก่อนยืนยัน การดำเนินการที่ย้อนกลับไม่ได้ต้องพิมพ์คำยืนยันก่อน

## แต่ละการดำเนินการทำอะไร

| การดำเนินการ | ผลที่เกิดขึ้น | ย้อนกลับได้ไหม |
| --- | --- | --- |
| แก้ไขข้อมูล (ชื่อ-สกุล) | แก้ได้เมื่อบุคคลนี้เชื่อมกับโรงพยาบาลของคุณเพียงแห่งเดียว ถ้าเชื่อมหลายแห่ง ระบบแจ้งให้ติดต่อผู้ดูแลระบบ ถ้ามีคนแก้ไปก่อน ระบบให้โหลดหน้าใหม่ | แก้ซ้ำได้ |
| เลขบัตรประชาชน | **แก้ไม่ได้** ถ้าเลขผิดให้ “ลบรายการ” (เมื่อระบบอนุญาต) แล้วเพิ่มใหม่ด้วยเลขที่ถูกต้อง | — |
| ออกลิงก์ใหม่ / ช่วยเปิดใช้งาน | สำหรับรายการที่ยังไม่เปิดใช้งาน ใช้ขั้นตอนเดิมของบุคลากร/อสม. และหน้าเปิดใช้งานบัญชีผู้ป่วย | ลิงก์ใหม่แทนลิงก์เดิม |
| รีเซ็ตรหัสผ่าน / คืนบัญชี | รีเซ็ตให้บุคลากร MEMBER, อสม. หรือผู้ป่วยที่มีอำนาจทั้งหมดอยู่โรงพยาบาลเดียวกันได้ โดยต้องเลือกวิธียืนยันตัวตนทุกครั้ง ถ้าอยู่นอกขอบเขตให้ผู้ดูแลระบบดำเนินการ | ลิงก์ต่อหน้าใช้ได้ 15 นาที; ลิงก์ออนไลน์ใช้ครั้งเดียวและหมดอายุใน 24 ชั่วโมง |
| ระงับ / คืนสิทธิ์ | หยุดหรือคืนสิทธิ์ทำงานในโรงพยาบาลนี้ (บุคลากร/อสม.) ตามเงื่อนไขเดิม เช่น อสม. ต้องไม่มีผู้ป่วยในความรับผิดชอบค้างอยู่ | ได้ |
| บัญชีนี้ไม่ใช่เจ้าของจริง | ล็อกบัญชีทันที ระงับสิทธิ์ในโรงพยาบาลนี้ ตัดการเข้าสู่ระบบ ยกเลิกการเชื่อม LINE ที่เกิดหลังเปิดใช้งาน และบันทึกประวัติ ถ้าระบบยืนยันการตัดการเข้าสู่ระบบไม่ได้ จะแจ้งให้กดยืนยันอีกครั้ง (การเข้าถึงภายในระบบปิดแล้ว) | คืนบัญชีด้วยขั้นตอนรีเซ็ตรหัสผ่านข้างต้น เมื่อยืนยันตัวตนสำเร็จ ระบบปลดล็อกและคืนเฉพาะสิทธิ์ที่ถูกระงับไว้ |
| ลบรายการ | ลบรายการและบัญชีที่ยังไม่เปิดใช้งานออกถาวร ยกเลิกลิงก์และการลงทะเบียนเองที่ค้าง | **ไม่ได้** |
| นำออกจากระบบ / สิ้นสุดการดูแล | ตัดสิทธิ์หรือสิ้นสุดการดูแลกับโรงพยาบาลนี้ เก็บประวัติทั้งหมดไว้ (ขั้นตอนเดิม) | ไม่ได้ ต้องเพิ่มใหม่ |

## ควรใช้ “ลบรายการ” หรือ “นำออกจากระบบ”

ใช้ **ลบรายการ** เมื่อเพิ่มรายการผิดและรายการนั้นยังไม่ถูกใช้เลย ระบบเป็นผู้ตัดสินว่าลบได้หรือไม่ และจะแสดงปุ่มเฉพาะเมื่อครบทุกข้อ

- ยังไม่เคยเปิดใช้งานบัญชี และยังไม่มีการเริ่มเปิดใช้งาน
- ไม่มีข้อมูลการดูแล นัดหมาย การมอบหมาย อสม. หลักฐาน หรือรายงาน
- บุคคลนี้ไม่เชื่อมกับโรงพยาบาลอื่นหรือบทบาทอื่น
- ไม่ใช่เจ้าของโรงพยาบาล และยังไม่ถูกนำออก

ข้อมูลที่มากับไฟล์ Excel ตอนนำเข้าผู้ป่วย (ข้อมูลติดต่อ ข้อมูลตั้งต้น สถานะผู้ป่วย ประวัติโรค) นับเป็นส่วนหนึ่งของรายการและลบไปพร้อมกันได้ แต่ถ้ามีการแก้ไขหลังนำเข้า ระบบจะนับเป็นข้อมูลและไม่ให้ลบ

ใช้ **นำออกจากระบบ** (บุคลากร/อสม.) หรือ **สิ้นสุดการดูแล** (ผู้ป่วย) ในกรณีอื่นทั้งหมด ประวัติการดูแลและการทำงานจะถูกเก็บไว้ ถ้าลบไม่ได้ หน้ารายละเอียดจะบอกเหตุผล

## เมื่อสงสัยว่าบัญชีไม่ใช่ของเจ้าของจริง

การลงทะเบียนเองด้วยเลขบัตร (ADR-0020) ไม่ได้พิสูจน์ว่าผู้ลงทะเบียนเป็นเจ้าของบัตร ถ้าเจ้าของจริงแจ้งว่าไม่ได้ลงทะเบียนเอง หรือพบการใช้งานผิดปกติ ให้กด **บัญชีนี้ไม่ใช่เจ้าของจริง** ทันที

- ใช้ได้กับบัญชีที่เปิดใช้งานแล้ว และบุคคลเชื่อมกับโรงพยาบาลของคุณเพียงแห่งเดียว ถ้าเชื่อมหลายแห่ง กรุณาติดต่อผู้ดูแลระบบ
- ใช้กับบัญชีของตัวเองหรือเจ้าของโรงพยาบาลคนอื่นไม่ได้
- หลังล็อกแล้ว ทุกการเข้าใช้งานของบัญชีนี้ถูกปฏิเสธตั้งแต่คำขอถัดไป
- หลังล็อกแล้ว เจ้าของจริงติดต่อโรงพยาบาลเพื่อรีเซ็ตผ่านแผง **คืนบัญชีให้เจ้าของจริง** หากบัญชีเกินขอบเขต OWNER ให้ผู้ดูแลระบบดำเนินการ

## รีเซ็ตรหัสผ่าน / คืนบัญชี (REC-1 และ REC-2A)

ที่หน้ารายละเอียดเลือก **รีเซ็ตรหัสผ่าน / คืนบัญชี** ระบบตรวจสิทธิ์และขอบเขตจากข้อมูลปัจจุบันทุกครั้ง OWNER ทำรายการได้กับผู้ใช้อื่นที่ไม่ใช่ ADMIN ดังนี้: (1) MEMBER, อสม. หรือผู้ป่วย เมื่อความสัมพันธ์ทั้งหมดของผู้ใช้ รวมรายการที่สิ้นสุดแล้ว อยู่โรงพยาบาล ACTIVE แห่งเดียว; (2) OWNER คนอื่นของโรงพยาบาลเดียวกัน เมื่อความสัมพันธ์ทั้งหมดของ OWNER เป้าหมายอยู่ที่โรงพยาบาลนั้น; และ (3) บัญชีที่มีบทบาท CAREGIVER อย่างเดียว เมื่อทุกความสัมพันธ์/สิทธิ์ผู้ดูแล รวมรายการที่สิ้นสุดแล้ว ชี้ไปยังผู้ป่วยที่มีประวัติ PatientHospitalRelationship อยู่โรงพยาบาลนี้แห่งเดียว ค้นหาบัญชี CAREGIVER อย่างเดียวได้จากช่องค้นหาเฉพาะในหน้าไดเรกทอรีด้วยเลขบัตรแบบตรงกันทุกหลัก

ผู้ใช้หลายโรงพยาบาล ผู้ใช้หลายบทบาทที่มี CAREGIVER บัญชีที่ถูกล็อก/มีงาน reconciliation ค้าง OWNER คนอื่นนอกโรงพยาบาลเดียวกัน และ ADMIN ให้ผู้ดูแลระบบดำเนินการ ผู้ดูแลระบบค้นหาด้วยเลขบัตรในเครื่องมือ ADMIN; ADMIN ทำได้กับ ADMIN คนอื่น แต่ห้ามรีเซ็ตบัญชีตนเอง การค้นหาถูกบันทึกตรวจสอบโดยไม่เก็บเลขบัตรใน audit ผู้ป่วยที่มี caregiver แต่ไม่ได้เป็น caregiver เองยังอยู่ในขอบเขตปกติของ OWNER

ก่อนออกลิงก์ ผู้ดำเนินการต้องเลือกวิธียืนยันที่ทำแล้วหนึ่งข้อ:

- **ตรวจบัตรประชาชนต่อหน้า** (`IN_PERSON_ID_CARD`)
- **วิดีโอคอลพร้อมเห็นใบหน้าและบัตรประชาชน** (`VIDEO_CALL_FACE_AND_ID_CARD`)
- **โทรกลับเบอร์ที่โรงพยาบาลบันทึกไว้** (`CALLBACK_PHONE_ON_HOSPITAL_RECORD`) — ห้ามใช้เบอร์ที่ผู้ร้องขอแจ้งมา

เลือก **ต่อหน้าบนเครื่องนี้** เพื่อส่งต่ออุปกรณ์ให้เจ้าของบัญชีกรอกเลขบัตรของตนเองและตั้งรหัสผ่าน ลิงก์ใช้ได้ 15 นาที เมื่อกดออกลิงก์ ระบบจะออกจากบัญชีของผู้ดำเนินการบนเครื่องนี้ก่อน แล้วเปิดหน้าตั้งรหัสผ่านให้ทันทีโดยไม่แสดงลิงก์ให้คัดลอก หากออกจากระบบไม่สำเร็จ ระบบจะยกเลิกลิงก์นั้นและแจ้งให้ลองใหม่ เลือก **ส่งลิงก์ออนไลน์** เพื่อแสดง QR/คัดลอก/แชร์ลิงก์ให้เจ้าของบัญชีเปิดบนอุปกรณ์ของตนเอง ลิงก์ออนไลน์ใช้ได้ 24 ชั่วโมงและใช้ได้ครั้งเดียว ทั้งสองแบบให้เจ้าของบัญชีกรอกเลขบัตรของตนเอง ระบบไม่เก็บเลขบัตรหรือภาพบัตร กรอกผิดครบ 5 ครั้งแล้วลิงก์ถูกยกเลิกและต้องออกใหม่หลังตรวจสอบตัวตนอีกครั้ง

หากผู้ให้บริการยืนยันตัวตนไม่รับรหัสผ่านใหม่ (ไม่ผ่านนโยบายความปลอดภัย) เจ้าของบัญชีจะเห็นข้อความที่ช่องรหัสผ่าน รหัสผ่านเดิมยังใช้ได้ และตั้งรหัสใหม่ซ้ำด้วยลิงก์เดิมได้จนกว่าลิงก์หมดอายุ หากระบบไม่ทราบผลกับผู้ให้บริการ บัญชีจะถูกกักไว้ชั่วคราว ให้ติดต่อผู้ดูแลระบบเพื่อตรวจสอบในหน้า **คืนบัญชีผู้ใช้** ซึ่งจะทำต่อให้เสร็จหรือยกเลิกให้กลับไปใช้รหัสผ่านเดิม แล้วจึงออกลิงก์ใหม่ได้

หากรีเซ็ตบัญชีที่ถูกล็อกสำเร็จ ระบบเปิดใช้งานบัญชี คืนความสัมพันธ์บุคลากร/อสม.ที่ถูกระงับโดย lock รายการเดิม และเก็บประวัติ lock ไว้ LINE ที่เชื่อมหลังเวลาล็อกจะยังไม่เชื่อมกับบัญชี ผู้ใช้เชื่อม LINE ใหม่เอง หากยังมี LINE binding ที่ใช้งาน ระบบส่งข้อความแจ้งว่ารหัสผ่านเปลี่ยนแล้ว การส่งลิงก์ออนไลน์เป็นการส่งต่อโดย OWNER (เช่น LINE chat); ระบบไม่ส่ง OTP หรือทำ recovery อัตโนมัติ

## เปลี่ยนรหัสผ่านที่ยังทราบอยู่

ผู้ใช้ทุกบทบาทสามารถเปิด **ตั้งค่าบัญชีส่วนตัว → เปลี่ยนรหัสผ่าน** เพื่อยืนยันรหัสผ่านปัจจุบันและตั้งรหัสผ่านใหม่ได้ หากรหัสผ่านปัจจุบันผิด ระบบแจ้งที่ช่องนั้นและจำกัดความถี่เพื่อป้องกันการเดารหัส รหัสผ่านใหม่จะออกจากระบบในอุปกรณ์อื่นเมื่อ Supabase ยืนยันสำเร็จ หากมี LINE binding ระบบส่งข้อความแจ้งการเปลี่ยนรหัสผ่าน
