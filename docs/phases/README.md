# Phase records

The files in this folder are historical phase handoffs, decision packs and contracts. They record what was decided and built at the time. They are not current runtime or business authority; for the precedence rules, see [AGENTS.md](../../AGENTS.md) §3.

## LINE MINI App retired (2026-11-17)

[ADR-0035](../adr/0035-retire-line-mini-app.md) retired the LINE MINI App. Phase records that describe the MINI channel, the `/line/workflow` gateway, scoped appointment pages, MINI deauthorization or the `DEMI_LINE_MINI_APP_*` variables (for example Phase 17J.3A, 17J.3B and LINE-QA.B1 to B2.4) are kept unchanged as history. That code and configuration no longer exist.
