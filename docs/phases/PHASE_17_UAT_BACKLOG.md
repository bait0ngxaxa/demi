## UAT-P0 gate list

รายการ UAT-P0 ที่ implementable หรือ reuse ได้ทันที: AUTH-01/02, NAV-01/02/03/04, PAT-01/02, CARE-01/03/04, APT-01/02/05, OSM-01/02, STAFF-01/02 และ OWNER-02.

APT-03/04 เป็น REQUIREMENT-GATED และขวางการยอมรับ appointment response/reschedule portion; ไม่ขวางการส่งมอบ patient appointment read-only ใน 17C. รายการ gated อื่นไม่ขวาง 17B/17C หากแยกจาก flow นั้น.

SUPPORT-01 เป็น gated optional enrichment ที่แนะนำเป็น 17M หลัง support/privacy contract; ไม่ขวาง core patient care journey.

## Recommended first implementation slice

**เริ่ม Phase 17B: Patient workspace และ own-scope foundation** หลัง review contract นี้: Patient Home, Personal/Work context projection, server-derived own scope และ own-profile/current-relationship read minimum. ใช้ National ID login, activation, Person/User, patient relationship, service policy และ UI shell ที่มีอยู่. ไม่เพิ่ม Patient mutation, DOB password, patient-specific clinical calculation หรือ family/medication schema ใน slice นี้.
