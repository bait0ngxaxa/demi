## Phase 17B/17C completion and next slice

Phase 17B ส่งมอบ Patient Home, Personal/Work context projection, server-derived own scope และ allowlisted own-profile/current-Hospital-relationship read โดย reuse National ID login, secure activation, Person/User, patient relationship, service policy และ UI shell ที่มีอยู่. ไม่มี Patient mutation, DOB password, patient-specific clinical calculation, family/medication/service-request schema หรือ speculative appointment response capability.
