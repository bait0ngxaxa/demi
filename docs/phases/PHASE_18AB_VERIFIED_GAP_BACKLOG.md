## 2. Proposed sequencing

1. **Phase 18C — Business & Clinical Rule Closure:** resolve the customer/clinical decisions used by G18-01 through G18-08, especially D01–D10 and the precise data-capture meanings. No code change in this phase.
2. **Separate authorization and snapshot review:** close RPT-24C actor/scope/privacy/revocation/audit/delivery and snapshot consistency gates before an implementation proposal for cohort export. HN-M08 remains separately deferred.
3. **Implementation authorization review:** only after binding decisions exist, scope minimal module-level changes by gap ID. Do not create speculative schema or a generic reporting framework.
4. **Acceptance:** verify source behavior with focused tests/integration checks, then synthetic end-to-end UAT. Customer acceptance is recorded explicitly; do not infer it from test results.

## 3. Deferred decisions and non-goals

- R24A-D01–D15 remain proposed/open; this backlog does not accept or duplicate them.
- No gap item authorizes runtime/schema/migration changes, new report/export endpoint, workbook edits, database writes, deployment/provider changes or real-patient data use.
- HN-M08 Network Export remains DEFERRED / NOT AUTHORIZED. Hospital OWNER is not Platform ADMIN; family relationship is not OSM assignment; Hospital hierarchy does not confer clinical access.
- Phase 18C is recommended as next phase, but is not started by this audit.
