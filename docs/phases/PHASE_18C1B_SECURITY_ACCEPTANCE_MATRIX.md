## 4. Audit and revocation acceptance

Future verified results ต้องแสดงทั้ง allow และ deny evidence:

- grant issue/change/revoke/expiry ระบุ actor, approver, capability/scope/policy version และ timestamp ตาม minimum metadata ที่อนุมัติ
- summary, Hospital summary, directory search และ detail open บันทึก outcome ตาม audit policy; denied/aborted/suspicious attempts มี event ที่ไม่บันทึก Patient data หรือ raw query
- role removal, account suspension, Hospital suspension, grant revocation/expiry และ relationship/Program eligibility change ถูกทดสอบทั้งก่อน request, หลัง page 1 และระหว่าง staged read
- audit retention, deletion, reader access, failure response และ incident routing ต้องมี approval evidence; audit schema pass อย่างเดียวไม่พิสูจน์ retention หรือ governance
- revoke ที่เกิดหลัง response ถูกส่งแล้วไม่สามารถถอนสำเนาที่ผู้ใช้เห็นได้; acceptance ต้องระบุขอบเขตเวลาและ guarantee จริงอย่างตรงไปตรงมา
